Why this is the real safety story

No single defense had to be perfect. Three independent layers — bash allowlist, network egress, path enforcer — each caught a different attack vector. The anomaly detector noticed the pattern (three blocks in one turn, source = tool-returned content) and escalated automatically. The model itself ultimately recognized it was being injected and produced a safe summary. The user got a useful answer with a warning, the admin got an actionable alert, and nothing — no data, no credentials, no requests — left Acme's perimeter.

LayeredEach block could have failed; the next would have caught it.
AutomaticNo human had to notice. The anomaly detector escalated within milliseconds.
AuditableEvery blocked attempt, every escalation, captured. Compliance-ready.
Not catastrophicAlice's turn still completed safely. The product kept working.
